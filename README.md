# iMed Team — kompaniya landing

Oddiy statik landing sahifa: backend yoki API bilan ulanmaydi. Loyihalar (TibMentor, MaqolaMed, TIBNOMA) iMed Team MCHJ qoshida: «Loyihalarimiz» bo‘limi (`products.items`), har biri logo va havolalar bilan.

## Ishga tushirish

```bash
npm install
npm run dev
```

Brauzer: [http://localhost:3002](http://localhost:3002)

## Matnni o‘zgartirish

Ertaga yangi ma’lumot kelsa **faqat** `lib/content.ts` ni tahrirlang:

- `hero`, `about`, `products`, `courses`, `team`, `contact`, `footer`
- Yangi mahsulot — `products.items` ga qo‘shing
- Yangi jamoa a’zosi — `team.members` ga qo‘shing
